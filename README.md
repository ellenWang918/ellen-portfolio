# Ellen’s portfolio

Minimal Next.js project using App Router, TypeScript, Tailwind CSS, and a local Alata font.

## Local development

```sh
npm install
npm run dev
```

Open http://localhost:3000.

## Checks

```sh
npm run lint
npm run typecheck
npm run build
```

The homepage component architecture is documented in [docs/homepage-architecture.md](docs/homepage-architecture.md).
